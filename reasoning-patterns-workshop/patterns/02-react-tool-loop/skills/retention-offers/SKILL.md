# Compliant retention offers (CP-12)

An at-risk account (usage trend < −15% OR ≥2 open Sev-A tickets) needs:
1. **Remediation first**: named commitment on each open Sev-A incident with an
   owner and target date (§3.3). A discount without remediation is non-compliant.
2. **Discount within cap** (§2.1–2.3): cap comes from the contract; >cap needs
   VP approval BEFORE communication; >25% prohibited outright.
3. **Notice-period check** (§4.1): contract notice terms prevail.
4. **Regulated entities**: add CP-19 compliance sign-off and cite it.
